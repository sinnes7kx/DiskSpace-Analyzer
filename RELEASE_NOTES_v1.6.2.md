# DiskSpace Analyzer v1.6.2

Windows executable release.

## Installation

1. Download `DiskSpace Analyzer 1.6.2.zip` from the release assets.
2. Extract the ZIP to a folder on your PC.
3. Launch `DiskSpaceAnalyzer.exe`.
