# DiskSpace Analyzer

[![Latest Release](https://img.shields.io/github/v/release/sinnes7kx/DiskSpace-Analyzer?label=Latest%20Version)](https://github.com/sinnes7kx/DiskSpace-Analyzer/releases/latest)

[![Download DiskSpace Analyzer](https://img.shields.io/badge/Download-Windows-blue?logo=windows)](https://github.com/sinnes7kx/DiskSpace-Analyzer/releases/latest)

**DiskSpace Analyzer** is a Windows desktop utility for exploring disk usage and finding out what is taking up space on your drives.

> **Latest packaged version:** 1.6.2  
> **Platform:** Windows  
> **Distribution:** Standalone `.exe` download

## Download

Download the latest Windows build from the repository's **Releases** page.

1. Open **Releases** on the right-hand side of the GitHub repository.
2. Select **v1.6.2** (or a newer release).
3. Download `DiskSpace Analyzer 1.6.2.zip` and extract it.
4. Run `DiskSpaceAnalyzer.exe`.

> This application is distributed as a Windows executable. This repository may not yet include its original Python source code.

## What it does

- Analyze disk usage on a Windows computer.
- Help identify files and folders that occupy storage space.
